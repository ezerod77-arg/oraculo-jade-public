Política de privacidad

Última actualización: 2 de noviembre de 2026.

Oráculo de Jade utiliza servicios de Google y YouTube para automatizar la gestión del canal de YouTube expresamente autorizado por su propietario.

Datos tratados

La aplicación puede acceder al identificador y datos básicos del canal autorizado, a los videos que administra y a credenciales OAuth necesarias para ejecutar acciones autorizadas. No solicita contraseñas de Google.

Finalidad y uso

Los datos se utilizan únicamente para subir contenido, gestionar metadatos, subtítulos y estado de publicación del canal autorizado; no se venden ni se usan para publicidad personalizada.

Almacenamiento y seguridad

Los tokens de autorización se almacenan en el entorno privado de ejecución, fuera del repositorio público, y solo deben ser accesibles por el administrador autorizado. Este sitio no almacena tokens ni realiza autenticaciones.

Compartición de datos

No se comercializan ni se comparten datos de la cuenta con terceros para fines comerciales. Se transmite a Google/YouTube lo necesario para utilizar sus APIs.

Conservación y eliminación

Las credenciales se conservan mientras sean necesarias para operar la automatización y se eliminan al desautorizar el canal o retirar la configuración. Para solicitar eliminación de datos o asistencia, escribir a ezerod77ia@gmail.com.

Revocar permisos

El propietario puede revocar la autorización desde las conexiones de su cuenta de Google. Al revocar la autorización, la aplicación deja de poder operar el canal hasta una nueva autorización.

Políticas de Google

El uso de datos obtenidos a través de servicios de Google se rige por la Google API Services User Data Policy y por los Términos de YouTube, cuando correspondan.
